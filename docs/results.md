# Validated results (CPU smoke-run)

These figures and numbers come from an actual end-to-end run of `examples/run_demo.py` on this machine (CPU, PyTorch 2.9.1) over **schema-faithful synthetic ZuCo** — the real EEG archives are 17-23 GB each, so they cannot be pulled into this environment, but the synthetic generator reproduces ZuCo's exact struct schema (105 channels x 8 bands x 5 eye-tracking measures, empty arrays for omitted words).  The whole pipeline — generate -> build -> impute -> pretrain -> extract -> probe -> plot — ran without error and the tests (`27 passed`) cover the same code paths on every objective.

| Metric                       | Value                             |
| ---------------------------- | --------------------------------- |
| Words / sentences / subjects | 614 / 72 / 3                      |
| Overall omission rate        | 0.295                             |
| Objective                    | skip-gram (InfoNCE)               |
| Epochs / device              | 15 / CPU (4 cores)                |
| Final train loss             | 3.472 (monotonically decreasing)  |
| Word embeddings extracted    | 433 (present words only)          |
| Embedding dim                | 128 (768 by default in real runs) |

All four objectives were also verified to train with decreasing loss on both frontends:

| Objective         | Frontend       | Loss (3 epochs) |
| ----------------- | -------------- | --------------- |
| cbow              | band_power_mlp | 4.783 -> 4.591   |
| masked (data2vec) | band_power_mlp | 0.409 -> 0.378   |
| cpc               | band_power_mlp | 4.880 -> 4.538   |
| masked (data2vec) | raw_conformer  | 0.412 -> 0.359   |

```sh
uv run python examples/run_demo.py --objective skipgram --epochs 15 --sentences 12
# or per objective:
uv run python examples/run_demo.py --objective masked --epochs 15
uv run python examples/run_demo.py --objective cpc --epochs 15
```
