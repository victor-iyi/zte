Parallax Chamber

How to read this page. Three encoders were trained separately, one per ZuCo task, so the task-vs-stimulus confound is removed structurally rather than statistically. Every number here is a closed-set retrieval readout on the held-out subject; free generation is not measured on this page. Off-diagonal transfer cells face a never-seen subject reading never-seen sentences — a null there is a finding, reported plainly, not a failure of the page.

The parallax view

sentences
vantage

One point per held-out sentence, coloured by semantic cluster and sized by word count; switch vantage to see the same sentences through a different task's encoder. Points that barely move between vantages are the task-invariant code — geometry all encoders agree on despite disjoint training stimuli. Coordinates are PCA-3D, Procrustes-aligned across models; axes are arbitrary. Hover shows the sentence and its per-model rank percentile.

Transfer flow

Link width is the rank-percentile lift over chance (0.5); a hairline is an honest null. Diagonal links (own task: new subject, familiar stimuli) wear their task's colour; off-diagonal links are new subject × new sentences — the strongest generalization cell this project can produce. Hover for the bootstrap CI and seed count.

Capacity dials

Certified menu size K per encoder on a log-2 dial, from the exact-length-pool menu audit; the small figure is the K=2 accuracy. An empty dial means no K was certified — that is the honest reading, never a rendering gap.

Percentile rain

Every drop is one held-out sentence's rank percentile under one model → sentence-set cell — the full distribution, not a summary. The dashed line is chance (0.5); rank percentile uses every query, not just the winners. Hover a drop for its sentence.

CKA triad

Edge thickness is linear CKA between two models' embeddings of the same sentences. High CKA between encoders that never shared a stimulus is convergent geometry — the parallax reading of a task-invariant code. A dashed edge means that pair was not measured.
